TECHNICAL ARCHITECTURE

Hardware truth. Zero software friction.

How a rooted Android phone transforms into a certified USB Human Interface Device.

01

Local or Wi-Fi Deck

Open the web deck on the plugged-in phone, or from any phone or laptop on your local Wi-Fi while relaxing on the couch.

→
02

FastAPI Daemon

Translates keystrokes, gestures, and thumbstick deflection into standardized USB HID scancodes.

→
03

Linux ConfigFS

Kernel exposes composite gadget on /dev/hidg0 with Report ID 1 (Keyboard) and Report ID 2 (Mouse AC Pan).

→
04

Host Computer

Target PC detects standard Dell USB Keyboard & Mouse over physical USB bus. Zero drivers needed.

REPORT ID 1 • 9 BYTES

Standard 104-Key Boot Keyboard

Full 6-key rollover payload with modifier byte (Ctrl, Shift, Alt, Win). Compatible with BIOS, GRUB, and all operating systems.

REPORT ID 2 • 6 BYTES

5-Button Mouse + AC Pan Scroll

Relative X, relative Y, vertical wheel, and official USB HID AC Pan (Usage 0x0238) for native horizontal scrolling.

QUICK START GUIDE

Up and running in three clean steps.

Deploy Emittr on your rooted Android device or NetHunter phone in under two minutes.

Step 1

Clone & Install

Run the autonomous installer inside your phone terminal as root:

git clone https://github.com/mranj/usb-typer.git cd usb-typer bash install.sh
Step 2

Magisk Persistence

Keep the composite gadget active even after phone reboots:

cp /opt/usb_hid_deck/02-usb-deck.sh /data/adb/service.d/ chmod +x /data/adb/service.d/02-usb-deck.sh
Step 3

Connect & Control

Plug in with an OTG cable and open the web app on your phone:

Direct URL: http://localhost:8088 or http://hid.keyboard
